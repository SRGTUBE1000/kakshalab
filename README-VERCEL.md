# Kaksha website — Vercel upload

This is the complete Kaksha Vite website source. It includes the supplied transparent app logo, responsive landing page, interactive syllabus tabs, FAQ accordion, and the Android download link.

## Upload to Vercel

1. Extract this ZIP.
2. In Vercel, choose **Add New → Project** and import/upload the extracted folder.
3. Vercel will detect Vite. If it asks for settings, use:
   - Build command: `npm run build`
   - Output directory: `dist`
4. Deploy.

No environment variables are required for this static site. All Android download buttons point to the supplied Google Drive APK link.
